# Smart File Organizer

A Python script that automatically organizes files in a folder.

## Features
- Sort files into folders (Images, Documents, Videos, etc.)
- Organize by year and month
- Detect duplicate files using hashing
- Move duplicates into a separate folder
- Show summary of processed files

## Technologies
- Python
- OS module
- Hashlib
- File system automation

## Run

python file_organizer.py
